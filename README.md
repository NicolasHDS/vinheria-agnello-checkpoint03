# Vinheria Agnello - Checkpoint 03

## O que foi feito
Sistema de estoque de vinhos em JavaScript. Tem um array de objetos com nome, tipo, safra e estoque, e funções para adicionar vinho, listar (forEach), mostrar estoque baixo (filter), somar o estoque (reduce) e deixar os nomes em maiúsculo (map). Os resultados aparecem no console e no alert.
